# 💰 Ailə Büdcəsi

Azərbaycan dilində ailə büdcəsi idarəetmə proqramı.

## Xüsusiyyətlər

- 📊 **Ana Səhifə** — Günlük limit, qalan pul, xərc xülasəsi
- ⚙️ **Büdcə Ayarları** — Gəlir, sabit və dəyişkən xərclər
- ➕ **Xərc Əlavə Et** — 9 kateqoriya ilə əlavə xərclər
- 📈 **Statistika** — Kateqoriya və tarix üzrə analiz

## Texnologiyalar

- React 18 + Vite
- LocalStorage (məlumatlar brauzerdə saxlanılır)
- Lucide Icons

## İşə Salmaq

```bash
npm install
npm run dev
```

## Deploy

Vercel ilə avtomatik deploy: `vercel --prod`
